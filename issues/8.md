## Overview
Transform Graviplex from a particle/physics visualization engine to a full 2D pixel art game engine capable of supporting games like Stardew Valley and Moonlighter. This roadmap covers all critical upgrades required for the engine.

### Current State
- Solid GPU rendering, input, and UI foundations.
- Missing key systems: sprite rendering, tilemaps, audio, save & load.

# Sprite Assets

Place your sprite images here for the `ecs_sprites` example.

## Required images:

| File | Recommended Size | Description |
|------|-----------------|-------------|
| `player.png` | 64x64 | Main player sprite |
| `enemy.png` | 48x48 | Enemy sprite |
| `pickup.png` | 32x32 | Collectible/pickup item |
| `ring.png` | 64x64 | Decorative ring (with transparency) |
| `bullet.png` | 16x16 | Small projectile |

## Supported formats:

- PNG (recommended, supports transparency)
- JPG/JPEG
- GIF
- BMP
- TIFF

## Tips:

- Use PNG format for sprites with transparency
- Keep sprite sizes as powers of 2 for best performance
- The atlas will automatically pack these into a single texture
